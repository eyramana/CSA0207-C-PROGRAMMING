The problem

Encryption protects content, not existence

An encrypted file still looks suspicious on a monitored network. Steganography hides the very fact that a message exists.

1

Encryption’s limitation

Ciphertext hides what is said but not that something was said, so it can attract interception or blocking.

2

The need for secrecy

A secure method must protect the information and conceal the communication itself.

3

Objective

Embed text in 24-bit BMP images with no visible change, then retrieve it exactly.

Method

How LSB steganography works

Each pixel byte’s lowest bit is replaced with one bit of the message. Changing a value by at most 1 out of 255 is invisible to the human eye.

BMP

Why BMP?

Raw, uncompressed pixels: no data loss and easy bit-level modification.

RGB

24-bit pixels

3 channels × 256 levels = 16,777,216 colours; the LSB of each channel carries one bit.

=

Same file size

Bytes are rewritten, never added, so the output file is as large as the original.

↑

Capacity

Grows with resolution: roughly one character per 8 pixel bytes.

Module 1 · Encoding

  1. Load the BMP once and validate it (24-bit, uncompressed).
  2. Build the payload: “STG1” marker, length and checksum, then the message bytes.
  3. Replace the LSB of each pixel byte with the next bit, skipping row padding.
  4. Write encoded.bmp in a single call. It looks identical.

Module 2 · Decoding

  1. Load the encoded BMP and find the pixel data offset.
  2. Read LSBs to rebuild the marker, length and checksum.
  3. Read length × 8 more LSBs and assemble each character.
  4. Verify the checksum, then print the message.
